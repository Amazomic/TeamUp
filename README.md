# TeamUp

Простое Android-приложение для случайного распределения игроков по командам.

- Название приложения: TeamUp.
- По умолчанию выбраны 6 игроков и 2 команды.
- Настройки доступны кнопками − и +; количество игроков можно выбрать от 2 до 30, команд — от 2 до 8.
- Для каждого игрока остаётся одно поле имени и цветной номер команды. До генерации игроки распределены по порядку и максимально поровну.
- **Generate teams** случайно меняет назначения, сохраняя порядок и поля имён.
- Количество игроков, число команд, имена и текущие назначения сохраняются на устройстве.

Debug APK: `app/build/outputs/apk/debug/app-debug.apk`.
